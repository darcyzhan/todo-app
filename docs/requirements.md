# TodoMaster Pro - 需求文档

## 一、产品定位

TodoMaster Pro 是一款面向个人及小团队的智能待办管理工具，通过多端协同（Web + 微信小程序），帮助用户高效管理日常任务、追踪习惯养成、分析时间投入，实现个人效能提升。

## 二、目标用户

- 需要管理大量待办事项的个人用户
- 希望养成良好习惯的自律人群
- 需要项目协作的小型团队
- 通过微信小程序随时处理待办的移动端用户

## 三、核心功能需求

### 3.1 用户认证

| 需求编号 | 功能 | 描述 | 优先级 |
|----------|------|------|--------|
| AUTH-001 | 用户注册 | 支持昵称+密码注册 | P0 |
| AUTH-002 | 用户登录 | 支持昵称+密码登录，返回 JWT | P0 |
| AUTH-003 | 令牌刷新 | Access Token 过期后通过 Refresh Token 续期 | P1 |
| AUTH-004 | 微信登录 | 小程序端通过微信授权登录 | P2 |

### 3.2 任务管理

| 需求编号 | 功能 | 描述 | 优先级 |
|----------|------|------|--------|
| TASK-001 | 创建任务 | 支持标题、描述、优先级、截止日期、所属项目 | P0 |
| TASK-002 | 任务列表 | 支持分页、筛选（状态/优先级/项目/标签）、排序 | P0 |
| TASK-003 | 任务详情 | 查看任务完整信息，包含子任务和评论 | P0 |
| TASK-004 | 更新任务 | 编辑任务所有字段 | P0 |
| TASK-005 | 删除任务 | 软删除或硬删除任务 | P0 |
| TASK-006 | 状态流转 | 待办 → 进行中 → 已完成 / 已取消 | P0 |
| TASK-007 | 子任务 | 支持为任务添加多个子任务，独立完成状态 | P1 |
| TASK-008 | 任务评论 | 支持为任务添加评论 | P1 |
| TASK-009 | 任务指派 | 支持将任务指派给团队成员 | P1 |
| TASK-010 | 提醒设置 | 支持为任务设置提醒时间 | P1 |
| TASK-011 | 附件上传 | 支持为任务上传附件 | P2 |

| PROJ-004 | 更新项目 | 编辑项目信息 | P0 |
| PROJ-005 | 删除项目 | 删除项目（可选级联删除任务） | P0 |
| PROJ-006 | 项目成员 | 邀请用户加入项目，分配角色 | P1 |

| 需求编号 | 功能 | 描述 | 优先级 |
|----------|------|------|--------|

| TAG-002 | 标签列表 | 查看所有标签 | P0 |
| TAG-003 | 任务打标签 | 为任务关联多个标签 | P0 |
| TAG-004 | 按标签筛选 | 通过标签筛选任务 | P1 |

### 3.5 习惯追踪

| HABIT-003 | 习惯统计 | 查看连续打卡天数、完成率 | P1 |

| 需求编号 | 功能 | 描述 | 优先级 |
|----------|------|------|--------|

| STAT-002 | 习惯统计 | 打卡连续天数、完成趋势 | P1 |
| STAT-003 | 通知列表 | 系统通知、任务提醒 | P1 |
| STAT-004 | 实时通知 | WebSocket 推送新通知 | P2 |

## 四、非功能需求

| 需求编号 | 类别 | 描述 |
|----------|------|------|
| NFR-001 | 性能 | API 平均响应时间 < 200ms |
| NFR-002 | 安全 | JWT 认证，密码 bcrypt 加密存储 |
| NFR-003 | 可用性 | Docker 一键部署，支持水平扩展 |
| NFR-004 | 兼容性 | Web 端支持主流浏览器，小程序兼容微信基础库 2.x+ |
| NFR-005 | 数据安全 | 支持数据库备份，定期导出 |
